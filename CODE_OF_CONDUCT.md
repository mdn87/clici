# Code of conduct

## The short version

Be decent to people. Argue about code, not about each other.

## What that means here

clici is a small project with one maintainer and a narrow purpose, so this does
not need to be long.

**Expected:**

- Assume the person you are replying to is acting in good faith.
- Keep criticism on the change: what it does, what it breaks, what it costs.
  "This joins a wrapped URL incorrectly" is useful. "This is careless" is not.
- Accept that a well-made change can still be declined for scope reasons. The
  README's **Current limitations** and **Planned next steps** describe what this
  tool is meant to be.
- Accept a technical disagreement resolving against you without escalating it
  into a personal one.

**Not accepted:**

- Personal attacks, insults, or demeaning comments.
- Harassment of any kind, in issues, pull requests, or private contact arising
  from this project.
- Sexualized language or imagery, and unwelcome sexual attention.
- Publishing someone's private information without their explicit permission.
- Sustained disruption: reopening settled arguments, brigading, or deliberately
  wasting a reviewer's time.

## Scope

This applies in the repository — issues, pull requests, discussions, commit
messages, code review — and to private contact that arises from participating
here.

## Enforcement

Report a concern to the maintainer through
[GitHub's private vulnerability reporting][private] or by direct message on
GitHub. Reports stay confidential.

[private]: https://github.com/mdn87/clici/security/advisories/new

The maintainer may edit or delete comments, close issues and pull requests, or
block accounts, in proportion to what happened, and is not obliged to debate a
moderation decision publicly.

## About this document

This is intentionally brief and specific to a one-maintainer project. If clici
grows contributors, replacing it with the [Contributor Covenant][cc] — which
has an established escalation and appeal process this does not — would be the
right move.

[cc]: https://www.contributor-covenant.org/
